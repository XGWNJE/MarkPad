# MarkPad 内置图标

[打开全量对照页](index.html)。页面复用正式卡片、设置与图标工坊，提供浅深主题、整套风格切换、同项并排放大与卡片尺寸调整；只使用测试名称和占位地址，不连接真实书签。需通过本地 HTTP 服务打开，例如仓库根目录运行 `python -m http.server 4178 --bind 127.0.0.1`，访问 `http://127.0.0.1:4178/design/builtin-icons/`。

- 正式资产：`../../assets/bookmark-icons/{clay,flat}/`，88 类网站、3 类文件夹，每类两套。重复站点复用；软陶默认，扁平作为轻量备选。
- 软陶：ImageGen 原生透明图集，每张最多 9 枚；按格裁切、等比缩放、补透明留白，导出 256×256 PNG。保留原生色彩与 alpha，不作程序抠图或重绘；沿用的选型样例采用相同导出规格。显示时共用固定柔灰底板。
- 扁平：可编辑 SVG，统一底色、留白与视觉比例，经过现有 SVG 安全清理。20 类缺少可复用清晰标识的入口采用字母标识，工坊已标明；具体来源、简化重绘与替代原因见 `receipts/`。
- 源与生成记录：`sources/`、`references/`、`sheets/`、`receipts/`。图集不是运行资源；扩展只加载每枚导出文件。品牌标识权利归原作者，第三方来源与许可随记录保留。
- 单枚新增：[提示词模板](../../core/icons/IconPrompt.js)是唯一文本来源；在图标工坊「生成单枚图标」复制当前风格模板，再附清晰标识生成并上传。使用说明见[图标工坊](../../docs/touch-icon-guide.md#图标工坊)。

自动匹配只看名称。正式 98 条书签中，95 条可自动匹配；「控制台」「服务器 - 轻量云 - 控制台」「AI 3D模型生成器」分别手动选择 VisionGuard、腾讯云、Tripo3D。手动选择保存标识 ID，随整套风格切换；上传文件保持优先。

检查：`npm test` 验证库、匹配、切换、上传与资产格式；`node design/builtin-icons/verify.mjs` 使用 `sharp` 或 Codex 自带依赖额外验证透明角、留白、SVG 可渲染性，生成 `verification.json`。可追加本机导出文件路径核对 98 条覆盖，不复制原文件或保存书签地址。
