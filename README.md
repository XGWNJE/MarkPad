# <img src="icons/icon.svg" alt="" width="32" height="32"> MarkPad

MarkPad 把 Chrome 书签栏显示为适合鼠标和触控操作的方形卡片，并接管新标签页。它直接读取和修改 Chrome 原生书签，适合想在桌面 Chrome 中用大卡片打开、整理常用网站的人。

打开一个新标签页即可使用；无需导入书签，也没有单独的书签库。

## 安装

需要桌面版 Chrome 和本仓库文件。

1. 在 Chrome 地址栏打开 `chrome://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择本仓库根目录。
3. 打开新标签页，查看书签栏中的卡片。

修改源码后，在扩展管理页刷新 MarkPad，再打开新标签页查看改动。

## 使用

| 操作 | 结果 |
| --- | --- |
| 点击书签或文件夹 | 打开网站或进入文件夹；用顶部面包屑返回上级。 |
| 点击网格末尾的操作卡片 | 在当前文件夹新建书签或文件夹；空文件夹也可使用。 |
| 右键或长按卡片 | 打开编辑、移动、图标和删除等操作。删除前会要求确认。 |
| 拖动卡片 | 调整顺序，或拖向左侧移动面板、右侧删除区域。 |
| 打开设置 | 切换浅色／深色主题，调整卡片、文字、顶部栏、背景光效和书签打开方式。 |

有图标的卡片在鼠标悬停或键盘聚焦时显示标题和域名；没有图标时文字持续可见。触控或手写笔首次点按有图标的卡片会先显示文字，再点一次才打开。

书签图标优先使用用户上传的文件，其次是仅按书签名称匹配的内置图标，最后在卡片可见时读取网站声明的图标。当前内置书签图标库为空；没有找到网站图标的卡片会保留文字。网站图标按完整书签地址缓存，右键选择「图标：重新获取网站图标」才会重新请求。

图标工坊接受 SVG、PNG/APNG、GIF、JPG 和 WebP。上传的位图宽高都至少为 256px；静态文件上限为 1 MB，GIF、APNG、动态 WebP 和 SVG 动画上限为 10 MB。上传图标和已获取的网站图标可调整背景与 40%–400% 的显示缩放。具体行为见[触控与图标说明](docs/touch-icon-guide.md)。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| `N` / `Shift+N` | 在当前文件夹新建书签／文件夹 |
| `Backspace` / `Alt+←` | 返回上级 |
| 方向键 | 在卡片间移动焦点 |
| `Enter` / `F2` / `Delete` | 打开／编辑／删除聚焦的卡片 |
| `Ctrl+Click` | 多选卡片 |
| `=` / `-` | 放大／缩小卡片 |
| `Escape` | 关闭弹窗或设置菜单 |

## 权限与数据

| 权限 | 用途 |
| --- | --- |
| `bookmarks` | 读取、创建、修改、移动和删除 Chrome 书签。 |
| `storage` | 保存自定义图标及网站图标缓存等本地数据。 |
| `tabs` | 按设置在新标签页或当前标签页打开书签。 |
| `<all_urls>` | 在对应卡片可见时读取书签网站声明的图标及图片资源。 |

编辑、移动或删除会直接修改 Chrome 原生书签；删除文件夹前会显示其子项数量并要求确认。外观偏好保存在本机，网站图标会在需要时向对应网站发起请求。

## 版本与开发

当前版本：`0.4.0`。这一版将新建入口移到网格末尾，改用弹窗编辑标题，将网站图标抓取移至后台，并移除书签搜索；完整历史见[完整变更记录](CHANGELOG.md)。

扩展直接加载原生 JavaScript 和 CSS，无构建步骤。需要运行自动测试时，安装 Node.js，在仓库根目录执行：

```powershell
npm test
```

预期结果是 Node 行为测试全部通过；失败时请保留测试输出。仅在升级 `gsap` 开发依赖后，先执行 `npm ci`，再执行 `npm run vendor:gsap` 重新生成内置文件。修改触控、弹窗、拖拽、图标或 Chrome API 后，还需刷新扩展并在新标签页检查实际交互。

代码入口是 `index.html` 和 `main.js`；`components/` 存放界面组件，`core/` 处理书签与图标，`css/` 存放样式，`tests/` 存放 Node 行为测试。维护约束和验证步骤见 [AGENTS.md](AGENTS.md)。
