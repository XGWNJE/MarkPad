# MarkPad

面向鼠标和触控操作的 Chrome 新标签页书签面板。<br>
把书签栏变成方形卡片，直接打开和整理 Chrome 原生书签，无需导入。

## 功能

- **浏览书签**：用卡片打开网站、进入文件夹，通过面包屑返回上级。
- **整理书签**：新建书签与文件夹、编辑名称、移动、排序和确认删除。
- **触控操作**：点按展开卡片文字，长按打开操作菜单；也支持鼠标和键盘。
- **调整外观**：切换浅色／深色，调整卡片大小、圆角、间距、全局字体、标题排版、顶部栏和背景光效；上传图标并调整背景与缩放。

当前版本：`0.4.0`。新建入口位于网格末尾，标题通过弹窗编辑，网站图标由后台获取；此版本已移除书签搜索。详见[完整变更记录](CHANGELOG.md)。

## 安装

需要桌面版 Chrome 和本仓库文件。扩展可直接加载，无需安装 Node.js、安装依赖或构建。

1. 下载并解压本仓库，或运行 `git clone https://github.com/XGWNJE/MarkPad.git`。
2. 在 Chrome 地址栏打开 `chrome://extensions/`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 MarkPad 根目录。
4. 打开新标签页，即可看到书签栏中的卡片；空文件夹会显示两张新建操作卡片。

更新仓库文件后，在扩展管理页重新加载 MarkPad，再打开新标签页。

## 使用

| 想做什么 | 操作 |
| --- | --- |
| 打开网站或文件夹 | 点击对应卡片；书签默认在后台新标签页打开，可在设置中改为当前页。 |
| 查看卡片文字 | 有图标时，鼠标悬停或键盘聚焦显示标题；触控／手写笔首次点按展开，再点一次打开。无图标时文字持续显示。 |
| 新建书签或文件夹 | 点击网格末尾的「新建书签」或「新建文件夹」，在当前文件夹创建。 |
| 编辑、移动或删除 | 右键或长按卡片打开菜单。删除会先确认；删除文件夹时显示子项数量。 |
| 拖拽整理 | 鼠标拖动卡片调整顺序，拖入文件夹或左侧移动面板；拖向右侧删除区域进入删除确认。 |
| 更换或调整图标 | 在卡片菜单中打开图标工坊，上传本地文件，或调整已获取的网站图标背景与缩放。 |
| 调整外观与打开方式 | 打开顶部设置菜单，修改主题、卡片、文字、顶部栏、背景光效及打开行为。 |

书签优先显示用户上传的图标，再匹配内置库，最后在卡片可见时获取网站图标。当前内置书签图标库为空，找不到图标时保留标题与域名。网站图标及未找到图标的结果会持续缓存；需要重试时，在卡片菜单选择「图标：重新获取网站图标」。

上传格式、大小限制、动画保留和背景编辑细则见[触控与图标说明](docs/touch-icon-guide.md)；配色与界面约定见[品牌与视觉规范](docs/markpad-brand-visual-guide.md)。

## 快捷键

在新标签页内使用；输入框中的按键不触发全局快捷键。

| 按键 | 操作 |
| --- | --- |
| `N` / `Shift+N` | 在当前文件夹新建书签／文件夹 |
| `Backspace` / `Alt+←` | 返回上级 |
| 方向键 | 在卡片间移动焦点 |
| `Enter` | 打开聚焦的卡片 |
| `F2` | 编辑聚焦卡片的名称 |
| `Delete` | 请求删除聚焦的卡片，确认后执行 |
| `Ctrl+点击` / `⌘+点击` | 切换卡片的选中状态，可多选 |
| `=` / `+` / `-` | 放大／缩小卡片 |
| `Escape` | 关闭弹窗或设置菜单 |

## 验证

运行自动测试需要 Node.js。在仓库根目录执行：

```powershell
npm test
```

预期结果是 Node 行为测试全部通过。修改 README 版本摘要、扩展版本或变更记录时，单独检查版本一致性：

```powershell
node --test tests/version-system.test.mjs
```

修改触控、弹窗、拖拽、图标或 Chrome API 后，还需重新加载扩展并在新标签页验收实际交互。仅在升级内置 GSAP 时需要安装开发依赖并重新生成文件，步骤见 [AGENTS.md](AGENTS.md)。

## 权限与数据

| 声明 | 用途 |
| --- | --- |
| `bookmarks` | 读取、创建、修改、移动和删除 Chrome 书签。 |
| `storage` | 在本机保存自定义图标、网站图标缓存和显示偏好。 |
| `tabs` | 在新标签页或当前标签页打开书签。 |
| `<all_urls>`（网站访问权限） | 按需读取 HTTP(S) 书签网站的图标声明及图片资源。 |

**编辑、移动和删除会直接修改 Chrome 原生书签。** MarkPad 没有独立的书签库；外观设置和图标数据保存在本机，未缓存的网站图标会在卡片可见时向对应网站发起请求。
