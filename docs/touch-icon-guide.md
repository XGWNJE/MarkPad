# MarkPad 触控与图标行为

本文档描述卡片交互和图标工坊。视觉令牌见[品牌与视觉规范](markpad-brand-visual-guide.md)；存储、后台边界与验证见[工程指南](engineering-guide.md)。

## 触控与卡片文字

- 主要触控目标不小于 44px；粗指针操作不依赖悬停。长按卡片与右键打开同一操作菜单。
- 聚焦卡片后按菜单键或 `Shift+F10` 打开同一菜单；上下方向键循环选择，Home／End 跳到首／末项，Enter／空格执行。Escape 关闭并返回卡片焦点；Tab 关闭菜单后继续页面导航。
- 卡片菜单显示操作目标名称；「重命名…」支持菜单内 F2，「移动到…」打开目录选择。图标操作按当前来源显示，文件夹不提供网站图标动作，不支持 HTTP(S) 的地址不提供网站图标重新获取。
- 有图标时，卡片文字默认收起；鼠标悬停、键盘聚焦或触控首次点按后，图标转为模糊底图，深色半透明文字层居中显示白色标题，书签下方显示域名，文件夹下方显示子项数量。再次点按才打开，点按卡片外区域可收起文字。
- 网页卡片按打开偏好直接在后台新标签页或当前页打开，不播放跳转动画。文件夹卡片轻收拢并淡化，内容准备好后轻淡入；Ctrl／Meta 多选和触控第一次展开不播放文件夹打开转场，减少动效时直接执行。
- 没有图标时，标题和域名在静态中性文字面上持续可见，直到自定义图标、内置图标或网站图标出现。展开文字不改变卡片尺寸。
- F2 和卡片右键菜单都通过弹窗编辑标题。删除书签或文件夹先进入确认弹窗；文件夹确认文案显示子项数量。
- 移动弹窗标明「当前位置」并禁止将当前父目录作为目标，避免原目录内意外改序。删除信息读取完成前禁止确认；读取失败可重试或关闭。确认删除后焦点进入下一项、上一项或设置入口；取消返回原卡片。
- 网格末尾的两张操作卡片用于在当前文件夹新建书签和文件夹，空文件夹也会显示。精细拖拽排序面向鼠标，触控优先保证点按、长按和弹窗操作。
- 鼠标拖动时邻卡让位，占位框显示插入位置；卡片间隙、跨行和末尾都可排序。文件夹左右边缘用于排序，中央停留 350ms、出现「移入文件夹」后松手才移入，离开中央撤销移入状态。
- 靠近窗口边缘展开移动或删除区域：删除区域在进入右侧触发区的第一次 dragover 就显示，不用等停留；左侧移动面板需要读取文件夹树，保留 180ms 停留。指针在已展开面板内时保持显示。
- 左右拖拽区域以悬浮面板显示，顶部与两侧保留间距；只有当前可见面板的内部可接收松手，外侧留白和圆角外区域不会触发移动或删除。右侧显示「松手后确认删除」，确认弹窗通过后才删除。
- 右侧投放按光标的实际坐标判定：命中测试把落点判给下层元素时，只要松手位置仍在删除区域（含 8px 容差）照样进入确认；浏览器没有派发 drop 时，用最近一次落在区域内的位置在 dragend 补一次。同一次拖拽只请求一次删除，Escape、失焦或切出页面取消的拖拽不会补上这次投放。
- 弹窗打开后焦点进入弹窗，Tab 在其中循环；Escape 与取消按钮执行相同清理，关闭后归还焦点。图标工坊取消会恢复预览，迟到的处理结果不会再次覆盖卡片。
- 设置弹层关闭时不参与 Tab 导航；名称保存与移动提交期间禁止重复确认，失败在底部显示原因并保留输入或目标，便于重试。
- 设置分为外观、文字、操作三个页签，左右方向键和 Home／End 切换分类；隐藏分类不参与 Tab。设置与卡片菜单互斥，打开弹窗、拖拽、导航或离开页面会收起菜单；菜单内部滚动保持展开，外部点击或滚动收起且不抢焦点。

文字层状态由 `:hover`、`:focus-visible`、`:focus-within`、`.text-revealed` 与 `.iconless` 驱动。标题与下方信息水平、垂直居中，全部使用白字；标题字重固定为 `900`。卡片与图标共同通过 `.card-surface` 裁切圆角，文字展开时同步模糊底图；文字层不叠加 `backdrop-filter`，否则悬停时的 3D 变换会让未按圆角裁切的模糊底图漏到卡片边缘，出现毛刺与漏光。

## 图标来源

书签图标按以下顺序显示：

1. 用户上传的自定义图标。
2. 仅按书签名称匹配的内置图标，默认品牌软陶，可在设置中整套切换为彩色扁平。
3. 卡片可见时读取的网站声明图标。
4. 无图标状态，显示标题与域名。

内置库包含 88 类网站与 3 类文件夹，两套共用名称规则，重复站点共用资产；20 类来源不足的入口以「字母标识」标明。自动匹配只读取书签名称；文件夹按完整名称匹配。「控制台」「服务器 - 轻量云 - 控制台」「AI 3D模型生成器」等泛名称需要在图标工坊搜索 VisionGuard、腾讯云或 Tripo3D 并应用一次。手动选择跟随整套风格切换，恢复默认后重新按名称解析。

网站图标可来自页面 `icon`、Apple Touch、Manifest 或同源 `/favicon.ico`；网页与 Manifest 的抓取和图标字节下载都由扩展后台完成，只处理 HTTP(S) 书签，按可见卡片请求。

网站图标按完整书签 URL 把图标字节缓存在本机，卡片显示不再访问网站。一次没取到图标不会永久记成「无图标」：网络不可达或图片渲染失败从 2 分钟后重试，图标字节都解不出来从 6 小时后重试，间隔逐次加倍、最长 24 小时；用户选择「重新获取网站图标」立即清除该地址缓存并重新请求。有自定义图标时，书签提供「恢复默认图标」，恢复按正常图标来源顺序解析；文件夹提供「恢复默认文件夹图标」。已显示网站图标时可通过「调整网站图标…」设置背景与缩放。网络与显示安全边界见[工程指南](engineering-guide.md#网站图标与缓存)。

## 图标工坊

图标工坊显示名称匹配结果，也可搜索或查看全部内置图标。支持 SVG、PNG/APNG、GIF、JPG 和 WebP；上传位图至少为 256×256，静态文件不超过 1 MB，动画不超过 10 MB。上传 SVG 先安全清理；允许安全的 SMIL 动画，拒绝脚本、事件、外链和嵌入对象。

新增网站可展开「生成单枚图标」，复制当前风格的提示词，附清晰品牌标识生成后上传。模板约束品牌形状、原色、72%–76% 主体比例、留白和材质；软陶输出透明 PNG，扁平优先 SVG、也接受 PNG。文件夹模板沿用灰绿底形与杏色徽记。模板不带书签地址；没有清晰参考时先补参考。

有当前图标时，窗口宽度至少 960px 的工坊并排显示编辑区与预览，窄屏纵向排列；没有当前图标时不显示空预览列。读取上传文件或分析自动背景期间禁用应用，状态与错误显示在固定底部；重新打开工坊或切换图标后，旧请求结果不会覆盖新会话。

上传图标与已获取的网站图标均可选择原样、自动融合、黑色、白色或自定义背景，并在 40%–400% 之间调整图标内容的缩放；100% 即填满卡片，位图按等比缩放不拉伸。背景与缩放只改变显示效果，不改变卡片边界。自动融合分析首帧边缘颜色，不通过 Canvas 重编码动图；GIF、APNG、动态 WebP 和安全 SVG 动画保留原始播放。

自定义颜色以 HEX 值保存，色轮、明暗面板和可用时的屏幕取色会同步预览。网站图标的背景和缩放按书签保存；取消预览时恢复卡片显示，应用时也不会把网站资源复制为自定义图标。
