# MarkPad 触控与图标行为

本文档描述卡片交互和图标工坊。视觉令牌见[品牌与视觉规范](markpad-brand-visual-guide.md)；存储、后台边界与验证见[工程指南](engineering-guide.md)。

## 触控与卡片文字

- 图标下方始终显示短标题，长名称省略；图标裁切和标题分开，浅深主题均保持可读。普通模式点击或轻触一次打开，整理模式切换选择，两种输入共用同一路径。
- 顶部固定新建、整理和更多入口。进入整理后可单选重命名、编辑图标，或多选移动、删除；实际宽度不足时，次要动作逐步收进更多菜单。操作说明集中在独立[帮助页](../help.html)。
- 移动面板支持选择目录及最前、最后或某项之前；当前目录同样可选。批量移动保持所选项目的原顺序。新建、重命名和批量提交等待存储完成，失败保留输入或未完成项目，避免重复写入。
- 删除先确认，文件夹读取成功后显示当前名称与子项数量；读取失败可重试。取消返回原入口，删除后原入口不可用时聚焦固定整理入口。
- 右键、长按、菜单键或 Shift+F10 打开卡片菜单；方向键、Home／End 导航，Enter／空格执行，Escape 关闭并返回焦点。它们是固定整理入口之外的快捷操作。
- 精细拖拽面向鼠标：邻卡让位，卡片边缘插入排序；文件夹中央停留 350ms、显示「移入文件夹」后松手才移入。进入右侧边缘立即显示删除区域，左侧移动面板保留 180ms 停留。
- 拖拽面板只接受可见矩形与圆角内的松手，留存缓冲不扩大投放边界。没有 drop 事件时，dragend 可用最后有效坐标补一次；Escape、失焦或切出页面会取消，单次拖拽最多请求一次删除。
- 网页按偏好直接在当前页或后台新标签页打开；文件夹轻淡入，系统减少动效时直接执行。整理选择不触发导航。
- 弹窗的 Tab 焦点限制在内部，Escape 走取消清理。设置分三个页签，左右方向键和 Home／End 切换；隐藏内容不参与 Tab。临时菜单互斥，导航、拖拽、外部滚动和页面失焦时收起，内部滚动保持展开。

## 图标来源

书签图标按以下顺序显示：

1. 用户上传的自定义图标。
2. 仅按书签名称匹配的内置图标，默认品牌软陶，可在设置中整套切换为彩色扁平。
3. 卡片可见时读取的网站声明图标。
4. 默认占位符与常显标题。

内置库包含 88 类网站与 3 类文件夹，两套共用名称规则，重复站点共用资产；20 类来源不足的入口以「字母标识」标明。自动匹配只读取书签名称；文件夹按完整名称匹配。「控制台」「服务器 - 轻量云 - 控制台」「AI 3D模型生成器」等泛名称需要在图标工坊搜索 VisionGuard、腾讯云或 Tripo3D 并应用一次。手动选择跟随整套风格切换，恢复默认后重新按名称解析。

网站图标可来自页面 `icon`、Apple Touch、Manifest 或同源 `/favicon.ico`；网页与 Manifest 的抓取和图标字节下载都由扩展后台完成，只处理 HTTP(S) 书签，按可见卡片请求。

网站图标按完整书签 URL 把图标字节缓存在本机，卡片显示不再访问网站。一次没取到图标不会永久记成「无图标」：网络不可达或图片渲染失败从 2 分钟后重试，图标字节都解不出来从 6 小时后重试，间隔逐次加倍、最长 24 小时；用户选择「重新获取网站图标」立即清除该地址缓存并重新请求。有自定义图标时，书签提供「恢复默认图标」，恢复按正常图标来源顺序解析；文件夹提供「恢复默认文件夹图标」。已显示网站图标时可通过「调整网站图标…」设置背景与缩放。网络与显示安全边界见[工程指南](engineering-guide.md#网站图标与缓存)。

## 图标工坊

图标工坊显示名称匹配结果，也可搜索或查看全部内置图标。支持 SVG、PNG/APNG、GIF、JPG 和 WebP；上传位图至少为 256×256，静态文件不超过 1 MB，动画不超过 10 MB。上传 SVG 先安全清理；允许安全的 SMIL 动画，拒绝脚本、事件、外链和嵌入对象。

新增网站可展开「生成模板」，复制当前风格的提示词，附清晰品牌标识生成后上传。模板约束品牌形状、原色、72%–76% 主体比例、留白和材质；软陶输出透明 PNG，扁平优先 SVG、也接受 PNG。文件夹模板沿用灰绿底形与杏色徽记。模板不带书签地址；没有清晰参考时先补参考。

工坊先展示当前图标；预览与编辑区按实际可用宽度并排或纵向排列。没有匹配图标时显示默认占位符。读取上传文件或分析自动背景期间禁用应用，状态与错误显示在固定底部；重新打开工坊或切换图标后，旧请求结果不会覆盖新会话。

上传图标与已获取的网站图标均可选择原样、自动融合、黑色、白色或自定义背景，并在 40%–400% 之间调整图标内容的缩放；100% 即填满卡片，位图按等比缩放不拉伸。背景与缩放只改变显示效果，不改变卡片边界。自动融合分析首帧边缘颜色，不通过 Canvas 重编码动图；GIF、APNG、动态 WebP 和安全 SVG 动画保留原始播放。

自定义颜色以 HEX 值保存，原生颜色控件、HEX 输入和可用时的屏幕取色同步预览。网站图标的背景和缩放按书签保存；取消预览时恢复卡片显示，应用时也不会把网站资源复制为自定义图标。
