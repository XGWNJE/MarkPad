# MarkPad 触控与图标行为

本文档描述卡片交互和图标工坊。视觉令牌见[品牌与视觉规范](markpad-brand-visual-guide.md)；存储、后台边界与验证见[工程指南](engineering-guide.md)。

## 触控与卡片文字

- 主要触控目标不小于 44px；粗指针操作不依赖悬停。长按卡片与右键打开同一操作菜单。
- 有图标时，卡片文字默认收起；鼠标悬停、键盘聚焦或触控首次点按后，深色磨砂覆盖层显示居中的白色标题，书签下方显示域名，文件夹下方显示子项数量。再次点按才打开，点按卡片外区域可收起文字。
- 没有图标时，标题和域名持续可见，直到自定义图标、内置图标或网站图标出现。展开文字不改变卡片尺寸。
- F2 和卡片右键菜单都通过弹窗编辑标题。删除书签或文件夹先进入确认弹窗；文件夹确认文案显示子项数量。
- 网格末尾的两张操作卡片用于在当前文件夹新建书签和文件夹，空文件夹也会显示。精细拖拽排序面向鼠标，触控优先保证点按、长按和弹窗操作。

文字层状态由 `:hover`、`:focus-visible`、`:focus-within`、`.text-revealed` 与 `.iconless` 驱动。标题与下方信息水平、垂直居中，全部使用白字；标题字重固定为 `900`。卡片与图标共同通过 `.card-surface` 裁切圆角，文字展开时同步模糊底图。

## 图标来源

书签图标按以下顺序显示：

1. 用户上传的自定义图标。
2. 仅按书签名称匹配的内置图标；当前内置库为空。
3. 卡片可见时读取的网站声明图标。
4. 无图标状态，显示标题与域名。

内置匹配只读取书签名称。网站图标可来自页面 `icon`、Apple Touch、Manifest 或同源 `/favicon.ico`；网页与 Manifest 的抓取由扩展后台完成，只处理 HTTP(S) 书签，按可见卡片请求。

网站图标按完整书签 URL 永久缓存，未找到图标的结果也会缓存。用户在卡片菜单选择「图标：重新获取网站图标」才清除该地址缓存并再次请求。有自定义图标时，菜单提供「图标：恢复网站图标」；恢复后可以手动重新获取。网络与显示安全边界见[工程指南](engineering-guide.md#网站图标与缓存)。

## 图标工坊

图标工坊提供按名称命中的内置候选和本地文件上传。支持 SVG、PNG/APNG、GIF、JPG 和 WebP；上传的位图原始宽高都至少为 256px。静态文件不超过 1 MB，GIF、APNG、动态 WebP 和 SVG 动画不超过 10 MB。上传 SVG 在保存前经过安全清理；允许安全的 SMIL 动画，拒绝脚本、事件、外链和嵌入对象。

上传图标与已获取的网站图标均可选择原样、自动融合、黑色、白色或自定义背景，并在 40%–400% 之间调整图标内容的缩放。背景与缩放只改变显示效果，不改变卡片边界。自动融合分析首帧边缘颜色，不通过 Canvas 重编码动图；GIF、APNG、动态 WebP 和安全 SVG 动画保留原始播放。

自定义颜色以 HEX 值保存，色轮、明暗面板和可用时的屏幕取色会同步预览。网站图标的背景和缩放按书签保存；取消预览时恢复卡片显示，应用时也不会把网站资源复制为自定义图标。
