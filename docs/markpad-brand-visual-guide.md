# MarkPad 品牌与视觉规范

本文描述当前品牌和界面样式约束。交互细节见[触控与图标说明](touch-icon-guide.md)，组件装配和动画交接见[工程指南](engineering-guide.md)。

## 品牌与图标

产品名固定为 **MarkPad**，对外描述为「面向触控操作的新标签页书签面板」。`Mark` 指书签与常用入口，`Pad` 指卡片面板；中文可用「书签触控板」辅助解释。

应用图标是温白底板上的 2×2 卡片网格：左上角墨色实心，其余三格中灰实心。源文件为 [icon.svg](../icons/icon.svg)，扩展使用 16、48、128px 的 PNG；新标签页使用 [tab-icon.svg](../icons/tab-icon.svg)。[图标导出页](../icons/export.html)用于手动导出，修改源图后应核对三个 PNG 尺寸和 16px 可辨识度。

应用 UI 图标集中由 `core/IconLibrary.js` 提供。新增图标优先复用成熟图标源的路径数据；只有现成资源不适用、无法引入依赖或用户要求定制时，才说明原因并集中手写 SVG。

## 配色与文字

- 采用 Lumen Index 风格：温白／中性深灰背景、黑白骨架、轻边框、低阴影与克制密度。危险操作使用危险色，书签图标保留自身颜色。
- 主题仅有浅色和深色，令牌分别放在 `variables.css` 的 `:root` 和 `:root[data-theme="dark"]`；主题配色由手动选择决定。
- 卡片本体透明、无边框，图标背景由图标显示偏好决定；面板与默认文件夹图标使用主题表面令牌。
- 默认采用系统字族，字体选择作用于整个页面。卡片标题字号与字距可调；文字层样式与状态见[触控与卡片文字](touch-icon-guide.md#触控与卡片文字)。

## 界面与动效

顶部为面包屑和设置入口；新建书签、文件夹位于网格末尾。设置按主题、书签卡片、文字、顶部栏、背景光效和打开行为组织。视觉调整仅覆盖已有界面的颜色、间距、圆角、状态、阴影和密度；新入口或装饰内容须有明确需求。

卡片保持正方形，当前指针动画为倾斜、磁吸和缩放。触摸、窄屏与系统减少动效时停用指针动画；卡片通过焦点和选中轮廓表达状态。精细交互见[触控与图标说明](touch-icon-guide.md)。

卡片采用原生 `squircle` 连续圆角，大小与曲线分别由 `--card-radius` 和 `--card-corner-shape` 控制，旧版浏览器保留普通圆角。图标与文字通过 `.card-surface` 的 `overflow: hidden` 按连续圆角裁切，并隔离图层；旧版浏览器使用圆弧 `clip-path`。新建卡片与图标工坊预览使用同一曲线。

背景光效由 WebGL2 绘制在卡片后方，可开关和调节强度，配色只来自 `--background-effect-*` 令牌。主题切换立即更新画面；暂停与降级策略见[运行资源与动画](engineering-guide.md#运行资源与动画)。

## 样式维护

先调整 [variables.css](../css/modules/variables.css) 的令牌，再映射到组件模块；颜色、尺寸和时长避免散落在组件中。

| 模块 | 职责 |
| --- | --- |
| `variables.css` / `base.css` / `animations.css` | 设计令牌、页面基础样式与共用动画 |
| `toolbar.css` / `breadcrumb.css` / `shortcuts.css` | 顶部栏、导航和快捷键列表 |
| `card.css` / `grid.css` | 卡片裁切、文字层、网格与新建操作卡片 |
| `dialog.css` / `icon-studio.css` | 弹窗和图标工坊，粗指针操作布局 |
| `drag-zones.css` | 左侧移动面板和右侧删除区域 |
| `settings.css` | 偏好控件与设置菜单 |
| `background-effect.css` | 全屏背景光效层 |

主要触控目标不小于 44px。按钮与菜单直接写动作和结果，如「新建书签」「重新获取网站图标」「应用图标」；动效用于表达状态变化，减少动效时使用静态反馈。
