# MarkPad 品牌与视觉规范

本文描述当前品牌和界面样式约束。交互细节见[触控与图标说明](touch-icon-guide.md)，组件装配和动画交接见[工程指南](engineering-guide.md)。

## 品牌与图标

产品名固定为 **MarkPad**，对外描述为「面向触控操作的新标签页书签面板」。`Mark` 指书签与常用入口，`Pad` 指卡片面板；中文可用「书签触控板」辅助解释。

应用图标是温白底板上的 2×2 卡片网格：左上角墨色实心，其余三格中灰实心。源文件为 [icon.svg](../icons/icon.svg)，扩展使用 16、32、48、128px 的 PNG；32px 资源用于高像素密度的工具栏显示。新标签页使用 [tab-icon.svg](../icons/tab-icon.svg)。[图标导出页](../icons/export.html)直接读取源图，用于手动导出；修改源图后应核对四个 PNG 尺寸、上下左右对称留白和 16px 可辨识度。

应用 UI 图标集中由 `core/IconLibrary.js` 提供。新增图标优先复用成熟图标源的路径数据；只有现成资源不适用、无法引入依赖或用户要求定制时，才说明原因并集中手写 SVG。

## 配色与文字

- 采用 Lumen Index 风格：温白／中性深灰背景、黑白骨架、轻边框、低阴影与克制密度。危险操作使用危险色，书签图标保留自身颜色。
- 主题仅有浅色和深色，令牌分别放在 `variables.css` 的 `:root` 和 `:root[data-theme="dark"]`；主题配色由手动选择决定。
- 卡片本体透明、无边框，图标背景由图标显示偏好决定；面板与默认文件夹图标使用主题表面令牌。
- 默认采用系统字族，字体选择作用于整个页面。卡片标题字号与字距可调；文字层样式与状态见[触控与卡片文字](touch-icon-guide.md#触控与卡片文字)。

顶部栏、网格与设置弹层共用内容宽度和页面留白令牌；小屏限制实际水平边距，保留用户保存的偏好值，避免挤空卡片。导航当前项、普通控件与说明文字形成字号和字重层级；卡片字号与内边距适应用户选择的尺寸，窄屏不覆盖用户标题字号。

## 界面与动效

顶部为面包屑和设置入口；新建书签、文件夹位于网格末尾。设置分为外观、文字、操作三个页签，标题、关闭按钮与页签固定，当前内容独立滚动。外观包含主题、卡片和顶部栏，文字包含字体与排版，操作包含打开行为与快捷键。视觉调整遵循现有令牌；新入口或装饰内容须有明确需求。

卡片保持正方形，内层以小幅倾斜、磁吸和缩放响应指针，根卡片只承载排序位移；拖动和落位期间暂停悬停。时长与幅度由 `--card-motion-*` / `--card-hover-*` 令牌控制，触摸、窄屏与系统减少动效时停用指针动画。排序占位、移入高亮、焦点和选中轮廓表达当前动作；精细交互见[触控与图标说明](touch-icon-guide.md)。

卡片采用原生 `squircle` 连续圆角，大小与曲线分别由 `--card-radius` 和 `--card-corner-shape` 控制，旧版浏览器保留普通圆角。图标与文字通过 `.card-surface` 的 `overflow: hidden` 按连续圆角裁切，并隔离图层；旧版浏览器使用圆弧 `clip-path`。新建卡片、排序占位、移入高亮与图标工坊预览使用同一曲线。

网页卡片直接执行打开，不播放卡片收拢或页面淡出转场。文件夹卡片打开时轻收拢与淡化，在 220ms 内恢复；数据准备完成后，新内容以 4px 位移在 180ms 内淡入，刷新和排序不触发入场。`--card-open-*` 与 `--folder-enter-*` 仅控制文件夹动效；系统减少动效时直接执行。

页面背景使用静态主题底色；浅色为温白，深色为中性深灰。页面、顶部栏、卡片文字面与弹层共同使用主题令牌，网站图标保留原有色彩；不设置独立动态背景。运行边界见[运行资源与动画](engineering-guide.md#运行资源与动画)。

设置与右键菜单使用轻弹层阴影，模态弹窗使用独立层级；提示、控件和内容面板复用圆角、间距与动效令牌。左右拖拽区域使用主题表面与留白悬浮在页面边缘，移动目录与删除确认文案保持清晰。

图标工坊有预览时在宽屏并排放置编辑区与卡片预览，窄屏纵向排列；没有当前图标时不保留空预览列。提交、读取和错误状态放在固定底部，减少布局跳动。

## 样式维护

先调整 [variables.css](../css/modules/variables.css) 的令牌，再映射到组件模块；颜色、尺寸和时长避免散落在组件中。

| 模块 | 职责 |
| --- | --- |
| `variables.css` / `base.css` / `animations.css` | 设计令牌、页面基础样式与共用动画 |
| `toolbar.css` / `breadcrumb.css` / `shortcuts.css` | 顶部栏、导航、设置弹层与偏好控件 |
| `card.css` / `grid.css` | 卡片裁切、文字层、网格与新建操作卡片 |
| `dialog.css` / `icon-studio.css` | 弹窗和图标工坊，粗指针操作布局 |
| `drag-zones.css` | 左侧移动面板和右侧删除区域 |

主要触控目标不小于 44px。按钮与菜单直接写动作和结果，如「新建书签」「重新获取网站图标」「应用图标」；动效用于表达状态变化，减少动效时使用静态反馈。
